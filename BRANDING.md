# Artwork provenance

## Active package and catalog icon: professional connections

Since version 1.0.1, this independently maintained connector uses an original
illustration of a blue professional profile card connected to two contact nodes
on a pale blue rounded tile. The release owner requested distinct, recognizable
artwork for the LinkedIn integration on 2026-11-16.

This is custom Flow Steward integration artwork, generated with the built-in
OpenAI image generation tool. It is not LinkedIn's official logo or [in] mark.
It does not claim LinkedIn sponsorship, endorsement or official partner status.
LinkedIn and its marks belong to their respective owner.

- Creation date: 2026-11-16.
- Source generation identifier: `exec-ba0f46bc-a5b1-4306-864a-81d1c99a7eef.png`.
- Generated source SHA-256: `57b0b676eb6db5b8e077ef7cfd0ac62da55cff87a938beaae4571edc64400f68`.
- Transformation: the release owner resized the generated artwork with macOS
  `sips` to a 128 x 128 RGB PNG. The supplied final PNG is copied byte-for-byte
  into the package, with no additional transformation.
- Final file: `icon.png`, 128 x 128 pixels, 15,318 bytes.
- Final SHA-256: `324708d4d88afaef003ad25866e06ee23247cfc811e99fc050f01fbbe97c15e5`.

Use this same custom icon in the application catalog and flowsteward.org card.
The release owner reviewed it at card size, and the publisher independently
reviewed the 128, 64 and 32 pixel renditions before publication. The pale tile
keeps the blue profile and connection motif visible against card backgrounds.
No provider artwork or third-party icon-library asset is incorporated; no
provider artwork permission is asserted. This record accompanies the custom
illustration in the release bundle.
